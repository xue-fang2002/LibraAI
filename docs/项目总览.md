# 项目总览：图书管理 / AI 问答系统（book_manager）

> 文档生成时间：2026-08-22
> 适用版本：D:\xianmufile 下的 Flask 插件化架构重构版

---

## 1. 一句话定位

一个基于 **Flask 的插件化（plugin）图书资料管理系统**：左侧栏按「模块」切换功能，内置 **AI 中心**（自动摘要 / 语义检索 / 智能问答），系统首页就是 AI 问答。新增功能 = 新增一个 `modules/` 下的文件夹，框架会自动发现并挂到侧边栏，无需改动 `app.py`。

---

## 2. 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Flask ≥ 3.0，Python（推荐 anaconda 3.11，兼容 3.9） |
| 数据库 | SQLite（`book_manager.db`，WAL 模式，懒建表/补列） |
| 前端 | Jinja2 模板 + 原生 CSS/JS，布局体系集中在 `layout_base` |
| AI（可选） | `llama_cpp`（本地 GGUF）/ `bge` 嵌入 / `faiss` 向量库；也可对接 ollama / 阿里 dashscope / transformers |
| 配置 | `PyYAML`，`config/*.yaml` |
| 运行 | 默认端口 `5005`，超级管理员 `admin`（初始密码首次启动时随机生成，见 `config/.init_admin_pwd`，或用环境变量 `ADMIN_INIT_PASSWORD` 指定） |

## 3. 目录结构与每个文件夹的功能

### 根目录
| 文件/目录 | 功能 |
|---|---|
| `app.py` | **应用入口**。`create_app()`：加载配置 → 初始化/补表数据库 → `PluginScanner` 扫描注册所有模块 Blueprint → 注册登录/登出/健康检查 → `before_request` 把当前用户注入 `g` → `context_processor` 注入侧边栏菜单 → 全局错误处理 + AI 调度器。 |
| `book_manager.db` | SQLite 主库（用户、图书、分类、权限、向量映射、文档分块、AI 任务、日志）。 |
| `server.log` | 运行日志（重启时覆盖）。 |
| `requirements.txt` | 依赖清单（Flask / PyYAML / numpy / sentence-transformers / dashscope 等）。 |
| `runbook.py` | 运维/初始化脚本（非核心入口）。 |
| `index.html` | 错误兜底页（非入口）。 |
| `.idea/` | PyCharm 工程文件，与运行无关。 |

### `config/` —— 全局与模块配置
| 文件 | 功能 |
|---|---|
| `app.yaml` | 全局配置：`app`(name/host/port/debug/secret_key/session_lifetime)、`database`(path/wal_mode/busy_timeout)、`uploads`(folder/max_file_size/allowed_extensions)、`ai`(默认兜底 default_mode/models_dir/embedding_model/llm_model)。 |
| `modules.yaml` | **模块开关与参数**：每个模块 `enabled` / `sort_order`；`ai_center` 块含 `ai_mode`(off/light/full)、`backend`(off/ollama/dashscope/transformers/llama_cpp)、`chat_thinking_mode`(divergent/conservative)、`security_lock`、`model_paths`(light_emb/full_emb/local_llm)、`ollama`/`dashscope`/`transformers`/`llama_cpp` 子配置。 |

### `core/` —— 全站共享基础设施（**不要随意改动内部契约**）
| 文件 | 功能 |
|---|---|
| `__init__.py` | 包标记。 |
| `plugin_scan.py` | **插件扫描器 `PluginScanner`**：遍历 `modules/*/__init__.py` 读取 `module_info` → 按 `modules.yaml` 过滤+排序 → 自动 `register_blueprint` → 生成侧边栏 `menu_items` → 聚合各模块自报的 `PERMISSIONS`/`config_entries`/`ai_features`。关键类属性：`DEFAULT_PUBLIC_MODULES={homepage,book_lib,chart}`（非管理员可见）、`NON_NAV_MODULES={ai_center}`（不进侧边栏）。 |
| `auth.py` | 权限/登录装饰器：`login_required`、`permission_required(perm)`、`module_enabled_required(module_id)`；`need_login_response(next_url)`（**未登录统一「提示」而非跳登录页**）；`SESSION_USER_KEY="user_id"`；`load_global_user()`（含 POST 类请求的同源 CSRF 校验）。 |
| `response.py` | 统一返回：`ok(data)` / `fail(msg,code)` / `paginate(...)` / `ApiResponse.build` → 固定结构 `{code,msg,data}`。 |
| `db_base.py` | **唯一数据库访问层**（~46KB）。用户/图书/分类/资源权限/模块访问权限/向量映射/文档分块/AI 任务/操作日志。所有模块读库都从这里 import 函数，禁止在别处写裸 SQL。 |
| `ai_interface.py` | **AI 门面（故障隔离）**：懒加载 `modules.ai_center.internal`，对外暴露 `global_ai_chat` / `ask_about_book` / `summarize_text` / `get_stats` / `ensure_ai_scheduler` 等。业务模块只依赖它，不直接 import `ai_center.internal`。 |
| `ai_config_store.py` | 读写 `modules.yaml` 的 `ai_center` 块，并强制刷新配置缓存（热生效，无需重启）。 |
| `config_loader.py` | `load_app_config()` / `load_modules_config()` / `get_config("modules.x.y")` / `is_module_enabled(id)` / `get_module_sort_order(id)`（带 5 分钟内存缓存，改配置后用 `force=True`）。 |
| `exceptions.py` | `global_exception_handler(app)` / `module_exception_guard("module_id")` / 异常类 `NotLoginException`、`PermissionDeniedException`、`ModuleDisabledException`。 |

## 4. 模块如何被发现与注册（架构核心）

```
app.py
  └─ PluginScanner()
       ├─ scan()：遍历 modules/<dir>/__init__.py，读取 module_info 字典
       ├─ 按 config/modules.yaml 过滤(enabled) + 排序(sort_order)
       ├─ register_blueprints(app)：app.register_blueprint(bp, url_prefix=route_prefix)
       └─ build_menu_items()：生成侧边栏（已按模块访问权限过滤）
  └─ context_processor 把 menu_items / module_urls / current_user 注入所有模板
```

每个模块在 `__init__.py` 里**自报元数据**，框架只负责收集（去中心化，新增模块无需改 `db_base` 或 `app.py`）：

- `module_info`（必填）：`module_id`、`display_name`、`icon`、`route_prefix`、`url_default_endpoint`、`blueprint`、`permission_required`、`description`、`version`
- `config_entries`（可选）：`[{name, desc, url}]` → 在「配置中心」按模块分组展示
- `PERMISSIONS`（可选）：`[(key, 名称)]` → 在「用户管理」按模块分组渲染勾选框
- `ai_features`（可选）：`[{key, name, desc}]` → 在「AI 中心」按模块分组展示

可见性规则：
- `DEFAULT_PUBLIC_MODULES` 之外的模块，非管理员在侧边栏看不到（但仍可手动访问 URL）
- `NON_NAV_MODULES`（如 `ai_center`）完全不进侧边栏
- 排序由 `modules.yaml` 的 `sort_order` 决定

## 5. 关键约定与「坑」（维护者必读）

1. **登录字段是 `account` + `password`**（不是 `username`）。登录接口 `POST /api/login`，响应读 `res.data.redirect`。
2. **未登录统一「提示」不跳转**：用 `need_login_response(next_url)`；AJAX 返回 `401 {"code":401,"need_login":true}`，页面渲染 `need_login.html`。**不要再写 `redirect(url_for("login_view"))`**。
3. **API 统一返回结构** `{code,msg,data}`：用 `core.response` 的 `ok()` / `fail()`，前端只读 `res.data.xxx`。
4. **`app.py` 默认不是 Flask debug 模式**：改 `routes.py` / `core/*.py` 后必须**手动重启**（进程常驻，模板 Jinja 改动会自动重载）。重启前务必用 `Stop-Process -Force`（PowerShell）清干净旧进程，避免**新旧两个进程同监听 5005** 导致请求打到旧代码。
5. **数据库只走 `core.db_base`**：禁止在业务模块写裸 `sqlite3`。注意函数签名，例如向量映射是 `add_vector_mapping(book_id, file_hash, chunk_index, faiss_index, preview=None)`（`faiss_index` 是位置参数）。
6. **调 AI 走 `core.ai_interface`**：`global_ai_chat(question, history=, mode=)` / `ask_about_book(book_id, question)` / `summarize_text(text, book_id=)`。不要直接 import `ai_center.internal.*`（做故障隔离）。
7. **读配置用 `core.config_loader.get_config("modules.x.y")`**；改 AI 配置走 `core.ai_config_store`。配置有 5 分钟缓存，调试时用 `force=True` 强制刷新。
8. **深色模式**：全局 `body` 没设 `color`，所有文字必须显式设色，且**不要纯黑 `#000`**（夜晚模式看不见）。
9. **模板继承**：子模板 `{% extends "layout_base.html" %}`，只填 `content` / `extra_css` / `extra_js` / `page_title` 块。模块自己的静态资源走 `static_url_path="/static/<module_id>"`。
10. **`ai_center/internal/config.py` 的 `_BASE_DIR` 是 4 层 `dirname`**（项目根 `D:\xianmufile`），模型路径都基于它解析，别再少算一层（否则模型被解析成 `modules\models\...` 而「不存在」）。

## 6. 如何添加一个新模块（Step by Step）

> 目标：新增一个「公告栏 `bulletin`」模块，侧边栏出现入口，管理员可见。

**① 建文件夹与 `__init__.py`**
```python
# modules/bulletin/__init__.py
from flask import Blueprint
import os

bp = Blueprint(
    "bulletin", __name__,
    template_folder=os.path.join(os.path.dirname(__file__), "templates"),
    static_folder=os.path.join(os.path.dirname(__file__), "static"),
    static_url_path="/static/bulletin",
)

module_info = {
    "module_id": "bulletin",
    "display_name": "公告栏",
    "icon": "📌",
    "route_prefix": "/bulletin",        # 路由前缀
    "url_default_endpoint": "index",
    "permission_required": None,         # None=所有人可见；"xxx"=需某权限
    "description": "系统公告展示",
    "version": "1.0.0",
    "blueprint": bp,
}

# 可选：在配置中心/用户权限/AI中心 里分组的自报元数据
config_entries = [{"name": "公告管理", "desc": "增删改公告", "url": "/bulletin/config"}]
PERMISSIONS = [("bulletin_manage", "公告管理")]
ai_features = []

from . import routes   # noqa: E402  必须在 blueprint 定义之后
```

**② 写路由 `modules/bulletin/routes.py`**
```python
from flask import render_template, request, g
from modules.bulletin import bp
from core.auth import login_required, permission_required
from core.response import ok, fail
from core.exceptions import module_exception_guard

@bp.route("/")
@module_exception_guard("bulletin")
def index():
    return render_template("bulletin/index.html", current_module_id="bulletin")

@bp.route("/api/list", methods=["POST"])
@module_exception_guard("bulletin")
@login_required
def api_list():
    return ok(data=[{"title": "欢迎", "text": "系统已上线"}])
```

**③ 写模板 `modules/bulletin/templates/bulletin/index.html`**
```html
{% extends "layout_base.html" %}
{% block page_title %}公告栏{% endblock %}
{% block content %}
<div class="main-content">  <!-- 注意：layout_base 已提供 .main-content，子页通常直接写内部内容 -->
  <h2>📌 公告栏</h2>
  <div id="list">加载中…</div>
</div>
{% endblock %}
{% block extra_js %}
<script>
fetch("{{ url_for('bulletin.api_list') }}", {
  method:"POST", headers:{"Content-Type":"application/json","X-Requested-With":"XMLHttpRequest"},
  body: JSON.stringify({})
}).then(r=>r.json()).then(j=>{ /* 渲染 j.data */ });
</script>
{% endblock %}
```

**④ 在 `config/modules.yaml` 启用并排序**
```yaml
modules:
  # ...已有模块...
  bulletin:
    enabled: true
    sort_order: 4
```

**⑤ 重启服务，验证**
- 管理员登录后侧边栏出现「📌 公告栏」
- 访问 `/bulletin/` 正常渲染
- 若声明了 `PERMISSIONS`/`config_entries`，去「配置中心 → 用户与权限」能看到分组

> 不删任何已有功能、不改 `app.py` 即可完成。
