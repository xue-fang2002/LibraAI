📖 使用指南

🌐 远程使用说明

本工具运行在部署服务器上，无法直接读写你本机磁盘。所有需要"操作某个文件夹"的功能，都请先把该文件夹压缩成 zip 上传；处理完成后结果会以 zip 下载 回到你的电脑。提取清单/路径类功能只回传清单，不下载文件本体。

📁 批量创建

建文件夹/文件：上传包含名称的Excel，指定列标题和目标子目录（相对，留空=根目录），即可批量生成。支持多级子目录（如：2024/Q1）。

建分表：上传需要加表的Excel（可多选），批量为它们新建工作表，可选复制模板内容和格式。

🔍 提取清单

上传文件夹 zip，提取其中的文件/文件夹名称，支持递归和按后缀筛选；结果可导出为 Excel/CSV 清单（下载回本地）。

✏️ 批量改名

简单替换：上传文件夹 zip，批量替换文件名中的特定文字。

Excel对照：上传文件夹 zip + 对照表（"原文件名"/"新文件名"两列），批量重命名；结果 zip 下载。

📊 Excel专项

单元格替换 / 转PDF：上传含Excel的文件夹 zip 处理；转PDF 与单元格替换需服务器装有 Microsoft Office。

删除分表：上传含Excel的文件夹 zip，按分表名称批量删除工作表。

📦 文件搬运

上传源文件夹 zip + 映射Excel，按映射把文件整理到对应子文件夹；结果（整理后的结构）以 zip 下载。
